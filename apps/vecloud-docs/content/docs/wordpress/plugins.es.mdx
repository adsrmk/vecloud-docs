## Buscar un plugin

Abre **Apps → Toolkit → Plugins** en la instalación correcta. Utiliza la búsqueda y la paginación para listas largas. Comprueba nombre, versión y estado de la fila antes de actuar.

## Instalar

1. Pulsa **Install** para abrir el catálogo.
2. Busca y selecciona el plugin.
3. Inicia la instalación y espera la confirmación.
4. Revisa la lista. Un plugin instalado no siempre está activo; actívalo desde su menú si hace falta.

El catálogo incluye los plugins de WordPress que muestra. Para plugins comerciales o propios, sigue el método del proveedor dentro de WordPress.

## Leer los cambios

Cuando se conoce una nueva versión, puede aparecer en azul junto a la instalada. Haz clic en ese número para abrir las notas. Cierra la ventana para volver a la lista. Leer las notas no inicia la actualización.

No todos los plugins ofrecen notas, por ejemplo los privados. En ese caso, consulta la información del proveedor antes de actualizar.

## Actualizar y automatizar

Crea una [copia](../backups/index.mdx), pulsa **Update** en la fila y deja que termine. Después prueba las funciones del plugin, como formularios o pagos.

El menú permite activar o desactivar las actualizaciones automáticas de ese plugin. Es una elección distinta de las actualizaciones de WordPress.

## Desactivar o eliminar

Desactiva desde el menú si el plugin no hace falta temporalmente. Comprueba qué funciones dependen de él. Eliminar lo retira de la instalación tras confirmar; conserva una copia si podrías necesitar ajustes o datos.

Si el resultado es incierto, revisa primero la lista actual. No repitas la misma actualización o eliminación solo por un error.
