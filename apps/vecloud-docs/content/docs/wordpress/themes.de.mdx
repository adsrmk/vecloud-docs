Ein Theme bestimmt das Erscheinungsbild deiner WordPress-Website. Im Toolkit verwaltest du die verfügbaren Themes; die weitere Gestaltung erfolgt direkt in WordPress.

## Themes öffnen

Öffne **Apps → Toolkit → Themes**. Suche das Theme und prüfe die installierte Version. Der Status kennzeichnet das aktive Theme.

<PortalScreenshot name="wordpress-themes" alt="Themeliste mit Updateaktionen" caption="Der Status zeigt das aktive Theme. Automatische Updates haben eine eigene Aktion. Das Beispiel nutzt Demodaten." />

## Installieren

Wähle **Install**, suche im Katalog und markiere das Theme. Warte auf den Abschluss und prüfe die Liste. Installation und Aktivierung sind getrennte Aktionen: Ein installiertes Theme muss nicht aktiv werden.

Folge bei eigenen oder kommerziellen Themes der Anbietermethode innerhalb von WordPress. Ein Child-Theme benötigt weiterhin sein Parent-Theme.

## Ein Theme aktivieren

1. Erstelle zuerst ein [Backup](../backups/index.mdx).
2. Öffne die Theme-Aktion und wähle **Activate**.
3. Lies die Bestätigung: Die Website nutzt danach dieses Theme und ihr Aussehen ändert sich.
4. Prüfe die öffentliche Website auf Desktop und Mobilgeräten, einschließlich Menüs, Widgets und Formularen.

Teste größere Wechsel nach Möglichkeit zuerst auf Staging. Einstellungen und Inhaltsblöcke können vom alten Theme abhängen.

## Aktualisieren

Wähle **Update**, wenn ein Update verfügbar ist. Warte auf die Bestätigung und prüfe die Website. Bewahre eigene Änderungen in einem geeigneten Entwicklungsablauf auf; Dateien des aktualisierten Themes können ersetzt werden.

Nutze **Enable automatic updates** oder **Disable automatic updates** beim Theme, um automatische Updates zu ändern. Das ist unabhängig von der WordPress-Kernupdateplanung.

## Aufräumen

Lösche nur nicht mehr benötigte Themes und prüfe Abhängigkeiten wie Child-Themes. Lies die Bestätigung sorgfältig. Prüfe bei unklarem Ergebnis erst die aktuelle Liste, bevor du die Aktion wiederholst.
