Plugins add functionality to WordPress. The toolkit helps you keep track of them, review what is changing and choose which installations or updates to apply.

## Find a plugin

Open **Apps → Toolkit → Plugins** for the correct WordPress installation. Use search to find a plugin and pagination for longer lists. Check the name, version and status of the row you are acting on.

<PortalScreenshot name="wordpress-plugins" alt="Installed WordPress plugins with status and version numbers" caption="Find the plugin row to check its installed version, status and available update." />

## Install a plugin

Once you have chosen a plugin that suits your website, install it from the catalog.

1. Choose **Install** to open the catalog.
2. Search for and select the plugin.
3. Start installation and wait for confirmation.
4. Check the list afterwards. An installed plugin is not necessarily active; use its action menu to activate it if required.

The catalog covers the WordPress plugins it lists. For a commercial or custom plugin, follow the publisher’s installation method within WordPress itself.

<PortalScreenshot name="wordpress-catalogue" alt="The WordPress plugin catalogue with example results" caption="Search by name and check the publisher before selecting a plugin." />

## Read the changes first

When a new version is known, it may appear in blue beside the installed version. Click the blue version number to open the change notes. Close the modal to return to the list. Opening the notes does not start an update.

Notes are not available for every plugin, such as a private plugin. Review the publisher’s information before updating in that case.

<PortalScreenshot name="wordpress-changelog" alt="Change notes opened from a blue plugin version number" caption="Read the notes before updating. Names, versions and notes in this example are demonstration data." />

## Updates and automatic updates

Create a [backup](../backups/index.mdx), click **Update** in the plugin row and let the operation finish. Then test the plugin’s functions, such as forms or payments.

Use the action menu to enable or disable automatic updates for that plugin. This is separate from automatic updates for WordPress itself.

## Deactivate or delete

Choose the deactivate action when a plugin is temporarily unnecessary. Check which functions depend on it. Deletion removes the plugin from the installation after confirmation; keep a backup if you may need its settings or data later.

If the outcome is unclear, check the current plugin list first. Do not repeatedly start the same update or deletion based on an error message.
