## Plugins vinden

Open **Apps → Toolkit → Plugins** bij de juiste WordPress-installatie. Gebruik de zoekbalk om een plugin te vinden en de paginering voor langere lijsten. Controleer de naam, versie en status van de rij waarop je handelt.

## Een plugin installeren

1. Kies **Install** om de catalogus te openen.
2. Zoek de gewenste plugin en selecteer die.
3. Start de installatie en wacht op de bevestiging.
4. Controleer daarna de pluginlijst. Een geïnstalleerde plugin hoeft nog niet actief te zijn; gebruik zo nodig het actiemenu om te activeren.

De catalogus is bedoeld voor de daarin beschikbare WordPress-plugins. Volg voor een commerciële of eigen plugin de installatiemethode van de leverancier in WordPress zelf.

## Eerst de wijzigingen lezen

Als een nieuwe versie bekend is, kan die naast de geïnstalleerde versie blauw worden weergegeven. Klik op dat blauwe versienummer om de wijzigingsnotities te openen. Sluit de modal om terug te keren naar de pluginlijst. Het openen van de notities start geen update.

Notities zijn niet voor iedere plugin beschikbaar, bijvoorbeeld bij een privéplugin. Controleer in dat geval de informatie van de leverancier voordat je bijwerkt.

## Bijwerken en automatische updates

Maak eerst een [back-up](../backups/index.mdx), klik op **Update** in de pluginrij en laat de actie afronden. Test daarna de functies waarvoor je de plugin gebruikt, zoals formulieren of betalingen.

Via het actiemenu schakel je automatische updates van die plugin in of uit. Deze keuze staat los van de automatische updates van WordPress zelf.

## Deactiveren of verwijderen

Kies de deactiveeractie in het menu wanneer de plugin tijdelijk niet nodig is. Controleer welke functionaliteit daarvan afhankelijk is. Verwijderen haalt de plugin uit de installatie na bevestiging; behoud een back-up als je instellingen of gegevens later nodig kunt hebben.

Bij een onduidelijke uitkomst controleer je eerst de actuele pluginlijst. Start dezelfde update of verwijdering niet herhaaldelijk op basis van een foutmelding.
