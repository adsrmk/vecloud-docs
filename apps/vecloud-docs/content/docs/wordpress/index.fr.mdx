Le toolkit WordPress vous aide à entretenir une installation depuis le panel. Les pages, articles et autres contenus restent gérés dans l’administration WordPress.

Pour un nouveau site, commencez par [Installer WordPress](./install.mdx). Pour reprendre un site chez un autre hébergeur, suivez [Migrer WordPress](./migrate.mdx).

## Ouvrir le toolkit

Ouvrez le site puis **Apps**. Cliquez sur **Toolkit** pour la bonne installation WordPress. Vous trouvez **General**, **Plugins**, **Themes**, **Users** et **Debug**. **Admin** ouvre l’administration WordPress si l’accès est disponible.

Si une installation existante manque, utilisez **Scan apps**. Ne réinstallez pas WordPress sur des fichiers existants uniquement pour faire apparaître le toolkit.

## Mettre à jour WordPress

Choisissez un moment où vous pourrez aussi vérifier les principales fonctions du site après la mise à jour.

1. Créez une [sauvegarde](../backups/index.mdx) des fichiers et de la base.
2. Dans **General**, vérifiez les versions installée et disponible.
3. Cliquez sur **Update** et lisez la confirmation.
4. Laissez l’opération se terminer. Une maintenance temporaire est possible.
5. Vérifiez site, administration et formulaires importants.

WordPress, extensions, thème et PHP doivent être compatibles. Testez d’abord une modification importante en staging si nécessaire.

## Mises à jour automatiques du cœur

Modifiez la planification sous **Automatic updates**. **Always update to the latest available version** suit toutes les versions disponibles. **Minor versions only** limite les mises à jour automatiques du cœur aux versions mineures. Enregistrez le choix.

Cette planification concerne WordPress. Gérez les mises à jour des extensions et thèmes dans leurs rubriques respectives.

## Modifier l’URL du site

L’action à côté de **Site URL** modifie `siteurl` et `home` dans WordPress. Vérifiez auparavant domaine, DNS et SSL de la nouvelle adresse. Cette modification ne remplace pas tous les anciens liens du contenu.

Conservez l’accès au panneau et une sauvegarde avant de changer l’adresse. Une URL incorrecte peut perturber connexion et chargement.

## Mode maintenance

**Maintenance mode** active ou désactive la maintenance de l’installation. Utilisez-le volontairement puis désactivez-le après vos travaux. Vérifiez le site public une fois le changement confirmé.

Pour plusieurs installations, utilisez [les mises à jour WordPress groupées](./bulk-updates.mdx) depuis le dashboard. La planification automatique du cœur reste un réglage distinct.
