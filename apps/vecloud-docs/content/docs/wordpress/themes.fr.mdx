Le thème détermine l’apparence de votre site WordPress. Utilisez le toolkit pour gérer les thèmes disponibles, puis personnalisez la présentation dans WordPress.

## Ouvrir les thèmes

Allez dans **Apps → Toolkit → Themes**. Recherchez le thème et vérifiez sa version installée. L’état identifie le thème actif.

<PortalScreenshot name="wordpress-themes" alt="Liste des thèmes et actions de mise à jour" caption="L’état identifie le thème actif. Les mises à jour automatiques ont une action distincte. Ce sont des données de démonstration." />

## Installer

Cliquez sur **Install**, recherchez le thème dans le catalogue et sélectionnez-le. Laissez l’installation se terminer puis vérifiez la liste. Installer et activer sont deux actions distinctes : un thème installé n’est pas forcément actif.

Pour un thème personnalisé ou commercial, suivez la méthode de l’éditeur dans WordPress. Un thème enfant nécessite aussi la présence de son thème parent.

## Activer un thème

1. Créez d’abord une [sauvegarde](../backups/index.mdx).
2. Ouvrez l’action du thème puis **Activate**.
3. Lisez la confirmation : le site utilisera ce thème et changera d’apparence.
4. Vérifiez le site sur ordinateur et mobile, notamment menus, widgets et formulaires.

Testez si possible les grands changements en staging. Réglages et blocs peuvent dépendre de l’ancien thème.

## Mettre à jour

Cliquez sur **Update** lorsqu’une mise à jour est disponible. Attendez la confirmation puis vérifiez le site. Conservez vos modifications avec un processus de développement adapté ; les fichiers du thème mis à jour peuvent être remplacés.

Utilisez **Enable automatic updates** ou **Disable automatic updates** à côté du thème pour modifier ses mises à jour automatiques. Ce réglage est indépendant de la planification du cœur WordPress.

## Nettoyer

Supprimez uniquement les thèmes devenus inutiles et vérifiez les dépendances, dont les thèmes enfants. Lisez la confirmation. En cas de résultat incertain, consultez d’abord la liste actuelle avant de recommencer.

Lorsqu’une mise à jour est disponible, sa nouvelle version peut apparaître en bleu. Ouvrez-la pour lire les notes disponibles avant de mettre à jour. Elles peuvent manquer pour les thèmes privés ou commerciaux. Le [récapitulatif groupé](./bulk-updates.mdx) permet aussi de consulter les notes des thèmes.
