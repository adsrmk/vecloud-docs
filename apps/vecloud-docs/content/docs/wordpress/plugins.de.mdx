## Ein Plugin finden

Öffne **Apps → Toolkit → Plugins** bei der richtigen WordPress-Installation. Nutze Suche und Seitenauswahl bei langen Listen. Prüfe Name, Version und Status der betreffenden Zeile.

## Installieren

1. Wähle **Install** für den Katalog.
2. Suche und markiere das Plugin.
3. Starte die Installation und warte auf die Bestätigung.
4. Prüfe danach die Liste. Installiert bedeutet nicht automatisch aktiv; aktiviere es bei Bedarf über das Aktionsmenü.

Der Katalog enthält die dort aufgeführten WordPress-Plugins. Folge bei kommerziellen oder eigenen Plugins der Installationsmethode des Anbieters innerhalb von WordPress.

## Änderungen lesen

Ist eine neue Version bekannt, kann sie neben der installierten Version blau erscheinen. Klicke auf die blaue Nummer für die Änderungsnotizen. Schließe den Dialog, um zur Liste zurückzukehren. Das Öffnen startet kein Update.

Nicht alle Plugins, etwa private, liefern Notizen. Prüfe dann vor dem Update die Anbieterinformationen.

## Updates und Automatisierung

Erstelle ein [Backup](../backups/index.mdx), klicke auf **Update** in der Pluginzeile und warte auf den Abschluss. Teste danach betroffene Funktionen wie Formulare oder Zahlungen.

Über das Menü aktivierst oder deaktivierst du automatische Updates dieses Plugins. Das ist unabhängig von den automatischen WordPress-Kernupdates.

## Deaktivieren oder löschen

Deaktiviere vorübergehend unnötige Plugins über das Menü und prüfe abhängige Funktionen. Löschen entfernt das Plugin nach Bestätigung aus der Installation. Bewahre ein Backup auf, falls Einstellungen oder Daten noch benötigt werden.

Prüfe bei unklarem Ergebnis zuerst die aktuelle Liste. Starte dasselbe Update oder Löschen nicht wiederholt allein wegen einer Fehlermeldung.
