## Applications disponibles

Ouvrez le site puis **Apps**. La liste présente les installations reconnues et, si disponibles, **Scan apps** et **Add application**. Les choix dépendent de l’offre et du site.

WordPress, Joomla et OpenClaw ont leurs outils propres. WooCommerce reste une fonctionnalité WordPress, pas une identité de site distincte dans le panneau.

<PortalScreenshot name="apps" alt="Liste des applications du site de démonstration" caption="Ouvrez Toolkit depuis la carte. Toutes les informations sont des données de démonstration." />

OpenClaw utilise son propre environnement de site. Tant qu’il y est installé, vous ne pouvez pas y installer d’autres applications. Utilisez un autre site pour WordPress ou Joomla.

## Nouvelle installation

<Steps>
<Step>
### Vérifier le site

Contrôlez le domaine et créez une sauvegarde si la destination contient déjà fichiers ou bases. Utilisez un emplacement vide prévu pour l’installation.
</Step>
<Step>
### Remplir le formulaire

Cliquez sur **Add application** et choisissez une application disponible. Pour WordPress et Joomla, vérifiez version et domaine. Laissez le chemin relatif vide pour l’emplacement par défaut ou saisissez `blog` pour un sous-dossier.

Renseignez les données administrateur demandées et conservez le mot de passe en sécurité. OpenClaw utilise d’autres réglages et ne demande pas de compte administrateur WordPress ou Joomla. Vérifiez également les extensions WordPress prédéfinies si elles sont affichées.
</Step>
<Step>
### Installer et vérifier

Cliquez sur **Install application** et laissez l’opération se terminer. Consultez les étapes suivantes du résultat puis ouvrez **Toolkit**, **Admin** ou **Dashboard**, selon l’application.
</Step>
</Steps>

## Retrouver une installation

Utilisez **Scan apps** si une installation existante manque. Le scan recherche des installations sans les restaurer ou réinstaller. Sans résultat, vérifiez le site et l’emplacement des fichiers.

## Retirer une application

Utilisez l’action de suppression de la bonne installation et lisez la confirmation. Conservez d’abord les données nécessaires. Après une erreur, vérifiez la liste **Apps** avant de supprimer ou installer de nouveau.

Pour WordPress, continuez avec [Le toolkit WordPress](../wordpress/index.mdx).
