Para un sitio Joomla utilizarás tanto el panel como su administración. El toolkit reúne datos de instalación y usuarios; el contenido y las extensiones se gestionan en Joomla.

## Abrir el toolkit de Joomla

Abre **Apps** del sitio y pulsa **Toolkit** junto a Joomla. Contiene **General** y **Users**. Revisa URL y ruta antes de modificar una cuenta.

**General** muestra los datos disponibles de versión, sitio y usuarios. **Admin** abre la administración Joomla. Inicia sesión con tu cuenta Joomla si se solicita.

## Actualizar Joomla

El panel puede indicar una versión nueva. Actualiza desde la administración Joomla. Revisa compatibilidad de extensiones y PHP y crea antes una [copia](../backups/index.mdx).

Para una versión principal nueva, sigue el procedimiento Joomla y las indicaciones mostradas. Un aviso de versión en VECloud no confirma que la actualización ya se haya realizado.

## Gestionar usuarios

1. Abre **Users** en el toolkit.
2. Pulsa **Add user** e introduce usuario, correo y contraseña solicitados.
3. Guarda la contraseña de forma segura y confirma.
4. Revisa la cuenta y sus permisos dentro de Joomla.

**Edit** modifica los datos mostrados. La nueva contraseña es opcional al editar; déjala vacía para conservar la actual. Elimina únicamente la cuenta correcta cuando ya no necesite acceso y lee la confirmación.

## Ajustes en Joomla

Gestiona contenido, extensiones, plantillas y permisos adicionales en la administración Joomla. Su toolkit no tiene las mismas pestañas de plugins y temas que el de WordPress.

Si no cargan los datos, comprueba instalación y base de datos y consulta el registro PHP en **Developer tools** cuando sea necesario.
