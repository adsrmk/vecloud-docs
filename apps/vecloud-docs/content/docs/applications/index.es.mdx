Las aplicaciones aportan el software del sitio, como un CMS o un servicio específico. Apps es el punto de partida para instalarlo y gestionar lo que ya existe.

## Aplicaciones disponibles

Abre el sitio y entra en **Apps**. Verás las instalaciones reconocidas y, cuando estén disponibles, **Scan apps** y **Add application**. Las opciones dependen del plan y del sitio.

WordPress, Joomla y OpenClaw tienen herramientas propias. WooCommerce se trata como funcionalidad de WordPress, no como identidad independiente del sitio.

OpenClaw utiliza su propio entorno de sitio. Mientras esté instalado, no puedes instalar otras aplicaciones allí. Usa otro sitio para WordPress o Joomla.

## Nueva instalación

<Steps>
<Step>
### Comprobar el sitio

Revisa el dominio superior y crea una copia si ya hay archivos o bases en el destino. Utiliza una ubicación vacía prevista para instalar.
</Step>
<Step>
### Rellenar el formulario

Pulsa **Add application** y selecciona una aplicación disponible. En WordPress y Joomla, revisa versión y dominio. Deja vacía la ruta relativa para la ubicación predeterminada o escribe `blog` para una subcarpeta.

Introduce los datos administrativos solicitados y guarda la contraseña de forma segura. OpenClaw usa otros ajustes y no pide una cuenta administrativa de WordPress o Joomla. Revisa también los plugins predeterminados si aparecen.
</Step>
<Step>
### Instalar y comprobar

Pulsa **Install application** y espera a que termine. Revisa los pasos posteriores del resultado y abre **Toolkit**, **Admin** o **Dashboard**, según la aplicación.
</Step>
</Steps>

## Detectar una instalación

Utiliza **Scan apps** si falta una instalación existente. Busca instalaciones; no las restaura ni reinstala. Si no encuentra nada, comprueba sitio y ubicación de los archivos.

## Eliminar una aplicación

Usa la acción de eliminación de la instalación correcta y lee la confirmación. Conserva antes sus datos necesarios. Tras un error, revisa **Apps** antes de eliminar o instalar otra vez.

Para WordPress, continúa con [El toolkit de WordPress](../wordpress/index.mdx).
