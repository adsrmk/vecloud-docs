Applications provide the software behind your website, such as a CMS or a dedicated service. Apps is the starting point for installation and ongoing management.

## Available applications

Open your website and choose **Apps**. It lists recognized installations and offers **Scan apps** and **Add application** when available. Applications and installation options depend on the plan and website.

WordPress, Joomla and OpenClaw have their own management options. WooCommerce is treated as WordPress functionality, not a separate website identity in the panel.

OpenClaw uses its own website environment. While it is installed on a website, you cannot install other applications there. Use a different website for WordPress or Joomla.

## A new installation

<Steps>
<Step>
### Check the website

Check the domain in the topbar and create a backup if files or databases already exist at the destination. Use an empty, intended installation location.
</Step>
<Step>
### Complete the form

Choose **Add application** and select an available application. For WordPress and Joomla, check the version and domain. Leave the relative installation path empty for the domain’s default location, or enter `blog` for a subdirectory.

Enter the requested administrator details and store the password securely. OpenClaw uses different settings and does not request a WordPress or Joomla administrator account. If preset WordPress plugins are listed, review those too.
</Step>
<Step>
### Install and check

Choose **Install application** and let installation finish. Review any follow-up steps in the result, then open **Toolkit**, **Admin** or **Dashboard**, depending on the application.
</Step>
</Steps>

## Discover an existing installation

Use **Scan apps** when an existing installation is missing from the list. A scan discovers installations; it does not restore or reinstall them. If nothing is found, check that the files belong to the correct website and location.

## Remove an application

Use the removal action for the correct installation and read the confirmation. Preserve required application data first. After an error, check the current **Apps** list before removing or installing again.

For WordPress, continue with [The WordPress toolkit](../wordpress/index.mdx).
