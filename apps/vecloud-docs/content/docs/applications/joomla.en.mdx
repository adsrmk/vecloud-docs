## Open the Joomla toolkit

Open your website’s **Apps** and choose **Toolkit** next to Joomla. It contains **General** and **Users**. Check the site URL and installation path before changing an account.

**General** shows available version, website and user information. **Admin** opens Joomla administration. Sign in with your Joomla account when asked.

## Update Joomla

The panel may report that a newer version is available. Update Joomla through its administrator panel. Check extension and PHP compatibility and create a [backup](../backups/index.mdx) first.

For a new major version, follow Joomla’s update procedure and the displayed guidance. A version notice in the VECloud toolkit does not confirm that an update has already happened.

## Manage users

1. Open **Users** in the Joomla toolkit.
2. Choose **Add user** and enter the requested username, email and password.
3. Store the password securely and confirm.
4. Check the account and appropriate permissions within Joomla itself.

**Edit** changes the displayed account details. The new password is optional when editing; leave it blank to keep the existing password. Remove only the correct account when access is no longer needed, and read the confirmation.

## Settings within Joomla itself

Use Joomla administration for content, extensions, templates and additional permissions. The Joomla toolkit does not have the same plugin and theme tabs as the WordPress toolkit.

If installation data does not load, check that the installation and database are reachable and review the PHP error log in **Developer tools** if needed.
