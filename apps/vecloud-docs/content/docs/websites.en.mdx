## Open your websites

In the Control Panel, go to **Domains**. Select a website to open its settings. The domain at the top shows which website you are managing; use the domain selector to switch websites.

## Add a domain

Click **Add domain** and choose the appropriate type:

- **Addon**: a separate website with its own domain name.
- **Subdomain**: an address under an existing domain, such as `shop.example.com`.
- **Alias**: an additional domain name for an existing website.

Enter the domain name and, where required, choose the related existing domain or website. Confirm with **Create**.

Adding a domain to the panel does not register it with a registrar. Also check the [DNS settings](./dns-ssl.mdx) before using your website.

## Settings for each website

Within a website, you can find:

- **Overview** for a summary of your website.
- **Apps** for applications and the WordPress toolkit.
- **Files** and **Databases** for your website content.
- **Backups** to browse and restore available backups.
- **SSL certificates**, **IP deny** and **Redirects** for connections and traffic.

Available options can vary by website and account.
