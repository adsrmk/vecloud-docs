## Consultez les sauvegardes disponibles

Ouvrez votre site et allez dans **Backups**. La liste correspond au site sélectionné. Vérifiez le domaine en haut du panel avant de continuer.

Chaque point de restauration indique les fichiers et les bases de données disponibles. Les points disponibles dépendent des paramètres de sauvegarde de votre hébergement.

## Créez une sauvegarde

Utilisez **Create backup** si cette action est disponible pour votre site. Attendez la fin de la sauvegarde avant de l’utiliser comme point de restauration.

## Restaurez votre site

1. Recherchez le point contenant le contenu souhaité.
2. Choisissez l’action de restauration de cette sauvegarde.
3. Sélectionnez les fichiers et/ou les bases de données à restaurer.
4. Vérifiez la sélection et confirmez la restauration.
5. Attendez la fin, puis vérifiez votre site.

La restauration remplace le contenu actuel sélectionné par celui de la sauvegarde. Les modifications effectuées après ce point peuvent être perdues.

## Restaurez WordPress

Un site WordPress complet nécessite à la fois ses fichiers et sa base de données associée. Vérifiez les deux éléments pour restaurer un site entier.
