## Ouvrez vos adresses e-mail

Ouvrez **Email** dans le menu principal et choisissez le domaine ou l’adresse à gérer.

## Configurez une boîte mail

Créez l’adresse et renseignez les informations demandées. Pour l’ajouter à un logiciel de messagerie, utilisez les paramètres de connexion affichés dans le panel : nom du serveur, port et réglage de sécurité.

Ces informations peuvent varier selon l’hébergement. Le domaine de votre site n’est donc pas nécessairement le nom du serveur de messagerie.

## Transférez les e-mails

Ouvrez l’adresse et gérez les destinataires du transfert. Vérifiez la destination avant d’enregistrer. Un transfert redirige les messages entrants ; les paramètres de la boîte déterminent si l’adresse sert également de boîte mail.

## Spam et listes de blocage et d’autorisation

Ajustez les options de filtrage disponibles dans les paramètres antispam. Utilisez les listes de blocage et d’autorisation pour les expéditeurs à bloquer ou à autoriser.

## Ouvrez le webmail

Utilisez l’action webmail du panel pour ouvrir votre boîte dans le navigateur. Vérifiez aussi les enregistrements DNS de la messagerie. Consultez [DNS et SSL](./dns-ssl.mdx).
