## Install WordPress

Open your website, go to **Apps** and choose **Add application**. Select WordPress and enter the requested installation and administrator details. Once installed, the application appears under your website.

## Open the toolkit

Click **Toolkit** next to your WordPress installation. Here you manage the installation, plugins, themes and users. Use **Admin** to open the WordPress dashboard.

## Manage plugins and themes

Open **Plugins** or **Themes** in the toolkit. Find the plugin or theme and use its action menu to see the available actions. Choose **Install** to open the catalog.

When a plugin update is available, the new version appears next to the installed version. Click the blue version number to read the available change notes. Choose **Update** to start the update.

Create a [backup](./backups.mdx) before major changes. Check your website after an update, including important forms and other features visitors use.

## Find existing installations

Is an existing WordPress installation missing from **Apps**? Use **Scan apps** to search that website for installations.
