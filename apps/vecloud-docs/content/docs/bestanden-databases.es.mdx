Utiliza el [gestor de archivos](./files/index.mdx) para editar, subir y gestionar archivos. Para conexiones, consulta [FTP](./files/ftp.mdx) o [SSH y SFTP](./files/ssh.mdx).

Las guías cubren [MySQL/MariaDB](./databases/index.mdx), [PostgreSQL](./databases/postgresql.mdx), [importación y exportación SQL](./databases/sql.mdx) y [phpMyAdmin](./databases/phpmyadmin.mdx).

Para una copia existente, sigue [copias y restauración](./backups/index.mdx). Importar SQL es distinto de restaurar todo el sitio.
