## Gestiona los archivos

Abre tu sitio y ve a **Files**. Navega por las carpetas con la lista de archivos y la ruta superior. Selecciona un archivo para ver las acciones disponibles.

El editor permite modificar archivos de texto compatibles desde el panel. Guarda los cambios con **Save**. Para transferir grandes cantidades de archivos, utiliza el acceso FTP/SFTP disponible.

## Abre una base de datos

Ve a **Databases** dentro de tu sitio. Elige la base de datos que quieras consultar o gestionar. Comprueba siempre el nombre, el tipo y el usuario asociado antes de hacer cambios.

Para bases de datos MySQL/MariaDB compatibles, usa la acción de phpMyAdmin para abrir su administración desde el panel.

## Usuarios de bases de datos

Utiliza los usuarios y sus permisos para controlar el acceso. Copia los datos de conexión del panel a tu aplicación y trata la contraseña como una credencial de acceso.

## Importa y restaura

Importar SQL y restaurar una copia son acciones diferentes. Para una importación, utiliza la opción de importación de la base de datos elegida. Para recuperar una copia existente, sigue [Copias de seguridad y restauración](./backups.mdx).
