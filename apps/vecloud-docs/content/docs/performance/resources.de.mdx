Ressourcengrafiken zeigen die Kapazität einer Websiteumgebung. Vergleiche eine Spitze mit Traffic, Updates und geplanten Aufgaben, um sie einzuordnen.

## Diagramm und Zeitraum wählen

Öffne **Domains → deine Website → Analytics → Resource usage**. Wähle **CPU**, **Memory**, **Storage performance (I/O)** oder **Processes**. Die Zeiträume sind **24h**, **1w** und **1 month**, standardmäßig 24 Stunden. Diese Auswahl ist getrennt von den Trafficgrafiken darüber.

**Last refreshed** zeigt den Abrufzeitpunkt.

## Was misst jeder Tab?

| Messung | Bedeutung |
| --- | --- |
| CPU | Prozessornutzung; 100 % entspricht einer vCPU. |
| Memory | Speicher der Websiteumgebung, nicht nur PHP memory_limit. |
| Storage performance (I/O) | Gelesene und geschriebene Bytes pro Sekunde. |
| Processes | Beobachtete Prozessanzahl. |

Längere Verläufe werden zusammengefasst: 30 Minuten für 24h, 3 Stunden für 1w und 12 Stunden für einen Monat. Linien zeigen zeitgewichtete Mittelwerte; Tooltips können auch Spitzen zeigen. Eine kurze Spitze kann die Durchschnittslinie übersteigen. Kurze Verläufe behalten ihre ursprünglichen Messungen.

## Grenzen und fehlende Werte

Soweit verfügbar, steht unter dem Diagramm die Grenze der letzten Messung. **Unlimited** bedeutet keine festgelegte Einzelgrenze, nicht unbegrenzte physische Serverkapazität.

Fehlende oder unbrauchbare Messungen bleiben Lücken und werden nicht zu Nullen. Prüfe bei leerer Grafik Website, Zeitraum und Meldung. Ein Ladefehler bedeutet nicht automatisch eine unerreichbare Website.

## Aus Messungen handeln

Teste eine Anpassung nach der anderen und vergleiche denselben Zeitraum erneut. Die Diagramme ändern keine Grenzen. Besprich eine nötige [Hostinganpassung mit dem Support](../websites/advanced.mdx). Bei zugeordnetem dediziertem Server ergänzt [Server metrics](./server-metrics.mdx) den Überblick über den gesamten Server.
