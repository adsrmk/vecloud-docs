Las gráficas muestran la capacidad utilizada por un entorno web. Compara los picos con el tráfico, las actualizaciones y las tareas programadas para entenderlos mejor.

## Elegir gráfica y periodo

Abre **Domains → tu sitio → Analytics → Resource usage**. Selecciona **CPU**, **Memory**, **Storage performance (I/O)** o **Processes**. Los periodos son **24h**, **1w** y **1 month**, con 24 horas por defecto. Esta selección es independiente de las gráficas de tráfico superiores.

**Last refreshed** indica cuándo se obtuvieron las mediciones.

## Qué mide cada pestaña

| Medición | Interpretación |
| --- | --- |
| CPU | Uso de procesador; 100% representa una vCPU. |
| Memory | Memoria del entorno, no solo PHP memory_limit. |
| Storage performance (I/O) | Bytes leídos y escritos por segundo. |
| Processes | Número de procesos observado. |

Los historiales largos se agrupan en intervalos: 30 minutos para 24h, 3 horas para 1w y 12 horas para un mes. Las líneas muestran medias ponderadas por tiempo; la información emergente también puede mostrar picos. Un pico breve puede superar la línea media. Los historiales cortos conservan las mediciones originales.

## Límites y datos ausentes

Cuando está disponible, el límite de la última medición aparece bajo la gráfica. **Unlimited** significa que no se registró un límite específico, no que el servidor físico tenga capacidad ilimitada.

Los datos ausentes o inutilizables quedan como huecos, no como ceros. Ante una gráfica vacía, revisa sitio, periodo y mensaje. Un error de carga no demuestra que el sitio esté caído.

## Pasar de la medición a la acción

Prueba un ajuste cada vez y compara el mismo periodo después. Las gráficas no cambian límites. Consulta un [ajuste de alojamiento con soporte](../websites/advanced.mdx). Si tienes un servidor dedicado asignado, [Server metrics](./server-metrics.mdx) añade la visión del servidor completo.
