## Installez WordPress

Ouvrez votre site, allez dans **Apps** et choisissez **Add application**. Sélectionnez WordPress et renseignez les informations d’installation et d’administration demandées. Une fois installée, l’application apparaît sous votre site.

## Ouvrez le toolkit

Cliquez sur **Toolkit** à côté de votre installation WordPress. Vous pouvez y gérer l’installation, les extensions, les thèmes et les utilisateurs. Utilisez **Admin** pour ouvrir l’administration WordPress.

## Gérez les extensions et les thèmes

Ouvrez **Plugins** ou **Themes** dans le toolkit. Recherchez l’extension ou le thème et utilisez son menu d’actions. Cliquez sur **Install** pour ouvrir le catalogue.

Lorsqu’une mise à jour est disponible, la nouvelle version apparaît à côté de la version installée. Cliquez sur le numéro bleu pour lire les notes de modification disponibles. Utilisez **Update** pour lancer la mise à jour.

Créez une [sauvegarde](./backups.mdx) avant les modifications importantes. Après une mise à jour, vérifiez votre site, notamment les formulaires et les fonctions utilisés par vos visiteurs.

## Retrouvez les installations existantes

Une installation WordPress existante n’apparaît pas dans **Apps** ? Utilisez **Scan apps** pour rechercher les installations sur ce site.
