Algunas aplicaciones necesitan una regla específica del servidor web. veCloud gestiona la configuración VirtualHost personalizada; no tienes que abrir un editor interno.

## Empieza por las funciones del sitio

Utiliza [Redirects](../dns-ssl/redirects.mdx) para redirecciones, [IP deny](../dns-ssl/ip-deny.mdx) para bloqueos y [Optimization](../performance/cache.mdx) para la caché. Estas páginas permiten gestionar los ajustes compatibles por tu cuenta.

## Solicitar una regla adicional

Indica a soporte el dominio, la ruta URL y el resultado que necesitas. Describe el comportamiento actual y el esperado y, si es posible, enlaza los requisitos de configuración de la aplicación. Un ejemplo de petición ayudará a comprobar el resultado.

Una configuración global de Nginx no es necesariamente adecuada para un solo sitio. Deja que veCloud valore su compatibilidad con las redirecciones, la seguridad y la caché existentes. No compartas archivos de configuración con contraseñas o claves.

## Después del cambio

Acuerda un momento para probarlo. Tras la confirmación, revisa las páginas, los formularios y las redirecciones afectados. Si el resultado no es el acordado, indica la URL exacta, la hora y el error. Pide a soporte que revise o revierta el cambio y evita modificar varios ajustes relacionados a la vez.
