title: Coordinate a server move
description: Understand what to prepare and check when veCloud moves your hosting environment.

An internal server move relocates the hosting environment within veCloud. veCloud plans and performs it; customers do not select a destination server or start an internal migration job.

Bringing a website from another hosting provider to veCloud? Follow [Move a WordPress website](../wordpress/migrate.mdx) or discuss your application with support.

## Agree on the preparation

Discuss the domain, reason for the move and suitable timing with support. Mention whether the website accepts orders, runs background jobs or connects to external services that allow specific IP addresses.

Agree whether and when to pause content changes. Keep important data and ask for confirmation of the recent backup available before the move. An older recovery point may not include recent changes.

## During the move

Follow the arrangements with support. Availability and management tools may be interrupted temporarily. Do not start a restore or a second move to speed things up. Contact support for internal progress and server logs.

## Check after confirmation

Test the public website, administration area, forms and any payments. Also check database connections, email and [backup access](../backups/index.mdx) for the services that moved.

If a public address changes, agree with support which external DNS records or IP permissions need updating. Report problems with the domain, time and exact error so they can be investigated directly.
