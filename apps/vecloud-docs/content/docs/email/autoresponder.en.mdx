title: Set an out-of-office reply
description: Have your email address send an automatic response during an absence.

An out-of-office reply lets senders know when to expect a response. Set the message and active period for the email address you want it to cover.

## Create a reply

Open **Email → the address → Manage → Out of office**. If no reply exists, choose **Out of office** beside the title.

1. Choose a **Start date** and optional **End date**.
2. Enter a recognizable subject and message.
3. Check **Enable autoresponder**. A saved reply can exist without being active if this is not enabled.
4. Choose **Add out-of-office reply**.
5. Review the displayed dates, message and status.

Write for an audience that can include unknown senders. State when you will reply and a business alternative, without personal travel details or internal contact information.

<PortalScreenshot name="mail-autoresponder" alt="Out-of-office form with dates, subject and message" caption="The dates and text are examples. Also check whether Enable autoresponder is selected." />

## Test the reply

Send from another email address during the configured period. Check both arrival in your mailbox and the automatic response at the sender. A saved reply with a future start date need not respond yet.

An out-of-office reply does not change forwarders, quota or mail routing. If no mail arrives at all, check [routing and DNS](../dns-ssl/mail-routing.mdx) first.

The panel sends the selected dates at 00:00 UTC. If the exact start or end time matters, account for your local time zone and test the reply around the start date.

<PortalScreenshot name="mail-autoresponder-saved" alt="Saved out-of-office reply showing its dates and Enabled status" caption="Check the dates and status after saving. Enabled indicates the reply is turned on for the chosen period." />

## Change or stop it

The current page displays an existing reply with **Delete autoresponder**. To change text, dates or enabled status, delete the existing reply and create a new one with the intended values. Verify the result before leaving.

For a reply without an end date, arrange to stop it yourself. Deleting the autoresponder does not delete received messages or the mailbox.

## Settings are missing

Use **Try again** if the section cannot load. After an unclear save failure, check whether the reply already appears before creating it again. Do not create another version based only on an error message.
