## Manage files

Open your website and go to **Files**. Navigate folders using the file list and the path at the top. Select a file to open the available actions.

The file editor lets you edit supported text files directly in the panel. Save your changes with **Save**. For larger file transfers, use your available FTP/SFTP access.

## Open a database

Go to **Databases** within your website. Choose the database you want to view or manage. Always check its name, type and associated user before making changes.

For supported MySQL/MariaDB databases, use the phpMyAdmin action to open database management from the panel.

## Database users

Use database users and their permissions to control access to a database. Copy the connection details from the panel into your application and treat the password as a sign-in credential.

## Import and restore

Importing SQL and restoring a backup are different actions. For an import, use the import option of the selected database. To restore an existing backup, follow [Backups & restore](./backups.mdx).
