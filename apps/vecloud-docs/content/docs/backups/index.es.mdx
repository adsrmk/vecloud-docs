Una copia de seguridad te permite volver a un momento anterior. Antes de restaurar, revisa qué copias están disponibles y qué contiene cada una.

## Buscar tus copias

Abre **Domains**, selecciona el sitio y entra en **Backups**. Comprueba el dominio en la barra superior. La lista corresponde a ese sitio.

<PortalScreenshot name="backups" alt="Historial de copias del sitio de demostración example.test" caption="El panel muestra la fecha, el almacenamiento y los archivos y bases de datos incluidos. Solo se utilizan datos de demostración. Haz clic para ampliar." />

## Interpretar la lista

| Columna | Significado |
| --- | --- |
| Started | Momento en que comenzó la copia. |
| Website files | Tamaño de archivos indicado y número de buzones, si está disponible. |
| Databases | Número de bases de datos indicado. |
| Restore | Abre los detalles y la acción de restauración. |

Un guion en el tamaño significa que no se ha recibido ese dato. No confirma que la copia esté vacía. Abre los detalles para comprobar el contenido.

## Crear una copia

1. Pulsa **Create backup** cuando esté disponible.
2. Espera la confirmación de que la solicitud se ha aceptado.
3. Comprueba la copia más tarde. Úsala solo cuando los componentes necesarios hayan finalizado correctamente.

<Callout title="Antes de un cambio">
Crea una copia reciente antes de una actualización importante, importación o cambio de configuración. El historial y la retención dependen del entorno de alojamiento; consulta la lista del panel.
</Callout>

## Elegir qué restaurar

WordPress necesita sus archivos y su base de datos. Los archivos incluyen plugins y contenido subido; la base de datos contiene publicaciones, ajustes y pedidos, entre otros datos.

Consulta [Restaurar una copia](./restore.mdx) para seleccionar y confirmar. Si la lista está vacía o aparece un error, consulta [Problemas con las copias](./troubleshooting.mdx).

## Pausar copias nuevas

Cuando está disponible, **Website backups** aparece bajo la lista. Un administrador autorizado de la cuenta puede cambiar **Disable backups**. El acceso solo como Collaborator no permite editarlo.

<Callout type="warning" title="Activado significa: sin copias nuevas">
Activar **Disable backups** detiene las copias automáticas y manuales del sitio y sus datos de correo, tanto en Enhance como en S3. Úsalo únicamente si quieres dejar de crear copias de forma deliberada.
</Callout>

Desactiva el interruptor para permitir de nuevo su creación y espera la confirmación. No inicia una copia inmediatamente. Los puntos existentes siguen disponibles; desactivar la creación no los borra ni bloquea la restauración.

Ante un resultado incierto, utiliza **Check status** y comprueba el estado actual. Cambiarlo repetidamente no resuelve un error de carga de la lista.
