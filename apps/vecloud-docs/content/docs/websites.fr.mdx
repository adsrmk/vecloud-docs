## Ouvrez vos sites web

Dans Control Panel, allez dans **Domains**. Sélectionnez un site pour ouvrir ses paramètres. Le domaine affiché en haut indique le site géré ; le sélecteur permet de changer de site.

## Ajoutez un domaine

Cliquez sur **Add domain** et choisissez le type adapté :

- **Addon** : un site indépendant avec son propre nom de domaine.
- **Subdomain** : une adresse sous un domaine existant, par exemple `boutique.exemple.fr`.
- **Alias** : un nom de domaine supplémentaire pour un site existant.

Saisissez le domaine et, si nécessaire, sélectionnez le domaine ou le site existant associé. Confirmez avec **Create**.

Ajouter un domaine au panel ne l’enregistre pas auprès d’un bureau d’enregistrement. Vérifiez aussi les [paramètres DNS](./dns-ssl.mdx) avant d’utiliser le site.

## Paramètres de chaque site

Vous trouverez notamment :

- **Overview** pour la vue d’ensemble du site.
- **Apps** pour les applications et le toolkit WordPress.
- **Files** et **Databases** pour le contenu du site.
- **Backups** pour consulter et restaurer les sauvegardes.
- **SSL certificates**, **IP deny** et **Redirects** pour les connexions et le trafic.

Les options disponibles peuvent varier selon le site et le compte.
