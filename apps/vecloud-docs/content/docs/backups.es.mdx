## Consulta las copias disponibles

Abre tu sitio y ve a **Backups**. La lista corresponde al sitio seleccionado. Comprueba el dominio de la parte superior del panel antes de continuar.

Cada punto de restauración muestra los archivos y las bases de datos disponibles. Los puntos disponibles dependen de la configuración de copias de tu alojamiento.

## Crea una copia de seguridad

Usa **Create backup** si esta acción está disponible para tu sitio. Espera a que la copia termine antes de utilizarla como punto de restauración.

## Restaura tu sitio

1. Busca el punto que contenga el contenido deseado.
2. Elige la acción de restauración de esa copia.
3. Selecciona los archivos y/o las bases de datos que quieras restaurar.
4. Revisa la selección y confirma la restauración.
5. Espera a que termine y comprueba tu sitio.

La restauración sustituye el contenido actual seleccionado por el de la copia. Puedes perder los cambios realizados después de ese punto.

## Restaura WordPress

Un sitio WordPress completo necesita tanto sus archivos como la base de datos asociada. Comprueba ambas partes al restaurar un sitio entero.
