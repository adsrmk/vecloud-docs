## Abre tus sitios web

En Control Panel, ve a **Domains**. Selecciona un sitio para abrir sus ajustes. El dominio de la parte superior indica qué sitio estás gestionando; el selector permite cambiar de sitio.

## Añade un dominio

Pulsa **Add domain** y elige el tipo adecuado:

- **Addon**: un sitio independiente con su propio dominio.
- **Subdomain**: una dirección bajo un dominio existente, como `tienda.ejemplo.com`.
- **Alias**: un dominio adicional para un sitio existente.

Introduce el dominio y, cuando corresponda, selecciona el dominio o sitio existente asociado. Confirma con **Create**.

Añadir un dominio al panel no lo registra en un registrador. Revisa también los [ajustes de DNS](./dns-ssl.mdx) antes de utilizar el sitio.

## Ajustes de cada sitio

Dentro de un sitio encontrarás, entre otras opciones:

- **Overview** para ver el resumen del sitio.
- **Apps** para las aplicaciones y el toolkit de WordPress.
- **Files** y **Databases** para el contenido del sitio.
- **Backups** para consultar y restaurar copias disponibles.
- **SSL certificates**, **IP deny** y **Redirects** para las conexiones y el tráfico.

Las opciones disponibles pueden variar según el sitio y la cuenta.
