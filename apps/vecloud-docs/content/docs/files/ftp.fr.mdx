Un compte FTP distinct est utile pour gérer les fichiers d’une partie précise du site. Choisissez son dossier d’accès en fonction du travail à effectuer.

## Choisir FTP ou SFTP

Ouvrez **Domains → votre site → FTP**. Les comptes FTP possèdent leurs propres identifiants et peuvent être limités à un répertoire. SFTP utilise les [identifiants SSH du site](./ssh.mdx), et non un compte FTP.

## Ajouter un compte FTP

Après avoir choisi le dossier, créez le compte, puis vérifiez son accès.

<Steps>
<Step title="Ouvrez Add FTP account">
Le bouton est disponible si FTP est activé pour le site et si votre offre dispose de capacité.
</Step>
<Step title="Choisissez un utilisateur et un répertoire">
Saisissez la première partie du nom ; le formulaire ajoute `@` et le domaine du site. Dans **Folder**, indiquez un chemin du site, par exemple `public_html/assets`. Une valeur vide donne accès à la racine du site `/`.
</Step>
<Step title="Définissez un mot de passe et enregistrez">
Utilisez au moins dix caractères comprenant minuscule, majuscule, chiffre et caractère spécial. Sélectionnez **Add account**, puis vérifiez la liste.
</Step>
</Steps>

<PortalScreenshot name="ftp-create" alt="Formulaire FTP avec le domaine et le dossier public_html/assets" caption="Saisissez la partie du nom avant @ et le dossier autorisé. Le formulaire ajoute le domaine." />

## Connecter votre client

Cliquez sur le nom du compte pour ouvrir **Login details**. Copiez le nom d’utilisateur complet et **Host** ; le port FTP indiqué est **21**. Utilisez FTP explicite sur TLS si le client et le serveur le prennent en charge. SFTP est un autre protocole et utilise SSH sur le port 22.

Conservez le mot de passe dans votre gestionnaire. Le portail ne révèle pas le mot de passe actuel. **Change password** permet de le remplacer ; mettez ensuite à jour les connexions enregistrées.

## Modifier l’accès au répertoire

Utilisez le crayon à côté de **Directory access**, choisissez le répertoire et enregistrez. La racine `/` couvre les fichiers de ce site, pas le serveur entier. Limitez l’accès des prestataires au répertoire nécessaire.

<Callout type="warn" title="Vérifiez l’option de suppression">
La confirmation **Delete FTP account** comporte une option distincte pour supprimer le contenu du répertoire. Laissez-la désactivée pour retirer uniquement l’accès. Supprimer le contenu de la racine peut rendre le site inutilisable.
</Callout>

<PortalScreenshot name="ftp-delete" alt="Confirmation de suppression FTP avec l’option du contenu décochée" caption="Laissez cette option décochée pour retirer uniquement l’accès du compte FTP." />

## Problèmes de connexion

Vérifiez le compte complet, l’hôte, le port et le protocole. Les identifiants FTP ne fonctionnent pas en SFTP. Si la connexion réussit mais qu’un dossier manque, vérifiez le répertoire autorisé et les [permissions des fichiers](./permissions.mdx).
