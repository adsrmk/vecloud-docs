La raíz pública o document root es la carpeta desde la que un dominio sirve los archivos del sitio. Una subida a otra ubicación puede finalizar correctamente mientras los visitantes siguen viendo contenido antiguo o un error.

## Empieza por la instalación

Abre **Domains → tu sitio → Apps** y comprueba la ubicación de la aplicación. Después abre **Files** y consulta la ruta de navegación. **Home** es el inicio del espacio de archivos de ese sitio.

Para WordPress, abre **Toolkit → General** y consulta **File path**. Para otra aplicación, revisa los datos de instalación que muestre.

`public_html` es una carpeta web habitual, pero la ubicación correcta depende del dominio y la aplicación. Sigue la configuración actual de tu sitio en lugar de dar una ruta por supuesta.

## Carpeta del dominio y ruta de instalación

En **Add application**, **Relative installation path** es relativa a la ubicación predeterminada del dominio elegido. Vacío significa esa ubicación; `blog`, una subcarpeta dentro de ella. No introduzcas automáticamente `public_html/blog` si `public_html` ya es la carpeta del dominio.

Para un sitio estático, coloca los archivos publicados en la carpeta prevista. Si el proyecto tiene una compilación, utiliza su salida en lugar de publicar todo el código fuente sin revisar. El [despliegue desde GitHub](../developers/github.mdx) tiene su propio ajuste **Publish directory**.

## Los archivos están, pero el sitio no los muestra

1. Comprueba el dominio seleccionado y la ruta completa.
2. Confirma que la subida terminó y que existen los archivos de entrada esperados.
3. Revisa [permisos](./permissions.mdx), configuración de la aplicación y [cachés](../performance/cache.mdx).
4. Comprueba que el [DNS](../dns-ssl/index.mdx) público apunte a este hosting.

Un alias puede compartir el entorno del sitio; otro dominio no implica otra carpeta. Pide a soporte que confirme la carpeta activa si no está clara. Mover archivos no cambia por sí solo la configuración del dominio.

Guarda exportaciones y archivos confidenciales fuera de la carpeta pública. Utiliza [subidas y transferencias](./transfers.mdx) para los archivos o [Migrar WordPress](../wordpress/migrate.mdx) para un traslado completo con base de datos.

Bajo la lista de **Files** aparece la document root configurada por dominio. Compárala con la ruta de carga o instalación. Un alias puede compartir asignación, así que revisa cada dominio mostrado en lugar de deducirlo por la carpeta.
