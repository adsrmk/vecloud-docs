## Gérez les enregistrements DNS

Ouvrez votre site et allez dans **DNS settings** pour consulter et modifier les enregistrements disponibles. Vérifiez que le DNS est réellement géré dans cet environnement. Avec des serveurs de noms externes, effectuez les modifications chez le fournisseur DNS externe.

Les enregistrements courants comprennent **A** et **AAAA** pour les adresses IP, **CNAME** pour une référence à un autre hôte, **MX** pour les e-mails et **TXT** pour les vérifications et la sécurité de la messagerie, entre autres.

## Cloudflare

Si vous utilisez une intégration Cloudflare, vérifiez que le domaine est associé à la bonne zone. Des options comme le proxy peuvent modifier la destination du trafic et la manière dont les vérifications de certificat atteignent votre site.

## Demandez un certificat SSL

1. Allez dans **SSL certificates** au sein de votre site.
2. Choisissez **Request certificate**.
3. Sélectionnez le domaine et confirmez la demande.
4. Vérifiez l’état et la date d’expiration une fois la demande terminée.

Le nom de domaine et l’accessibilité du site doivent être corrects pour que la demande aboutisse.

## Redirigez les visiteurs vers HTTPS

Utilisez **Enforce HTTPS** pour rediriger les visiteurs vers la connexion sécurisée. Vérifiez d’abord qu’un certificat valide est actif pour le domaine.

## DNSSEC

DNSSEC protège la vérification des réponses DNS. Pour fonctionner, les paramètres du fournisseur DNS et les données du bureau d’enregistrement doivent correspondre. Gérez DNSSEC auprès des fournisseurs de vos serveurs de noms et de votre enregistrement de domaine.
