Le panel comporte deux niveaux : votre compte et vos sites. Cette distinction vous aide à retrouver les bons réglages lorsque vous passez de l’un à l’autre.

## Navigation principale

Connectez-vous sur [panel.vecloud.eu](https://panel.vecloud.eu). **Overview** résume votre compte. **Domains** ouvre les sites et **Email** la gestion du courrier. **Users**, **Integrations** et **Profile** concernent le compte ou l’organisation.

<PortalScreenshot name="domains" alt="Liste des domaines avec le site de démonstration example.test" caption="Ouvrez un site depuis Domains. Les captures utilisent des données de démonstration et les libellés anglais des commandes." />

## Ouvrir un site

1. Allez dans **Domains**.
2. Recherchez le domaine ou filtrez par état.
3. Cliquez sur le nom du domaine.
4. Vérifiez le domaine de la barre supérieure avant toute modification.

La barre latérale affiche maintenant les rubriques du site, dont **Apps**, **Files**, **Backups** et **DNS settings**. **Domains** dans la barre supérieure revient à la liste. Le sélecteur de domaine change de site lorsqu’il est disponible.

<PortalScreenshot name="domain-switcher" alt="Sélecteur du domaine dans la barre supérieure avec le domaine actuel sélectionné" caption="Ouvrez le sélecteur pour changer de site. Vérifiez ensuite le domaine dans la barre supérieure." />

## Recherche et mobile

Utilisez **Search** pour la recherche générale. Sur petit écran, ouvrez le menu de navigation pour choisir une rubrique. Si un tableau contient trop de colonnes, faites défiler le tableau horizontalement.

## Une option manque

Les actions dépendent de votre rôle, offre et site. Une entrée désactivée n’est pas une fonctionnalité active. Si un site manque, demandez au propriétaire de vérifier vos droits dans [Équipe et accès](./team.mdx).

Cette documentation utilise les libellés anglais du panneau. Réglez votre langue d’interface dans [Votre profil](./profile.mdx).

## L’aide de votre écran

Le point d’interrogation près d’un titre ou réglage ouvre l’aide correspondante dans un panneau latéral. Son lien ouvre l’article complet. **Support docs**, au bas de la navigation, mène à la base de connaissances.

Le [guide du dashboard](./dashboard.mdx) explique bande passante, mises à jour WordPress et SSL. Si une rubrique manque, vérifiez d’abord le compte et le site ouverts.
