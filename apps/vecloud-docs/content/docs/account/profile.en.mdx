## Open your profile

Choose **Profile** in the main sidebar. **My account** contains your profile, security and devices. These settings belong to your own login.

<PortalScreenshot name="profile" alt="Account settings with a fictitious name and demo device" caption="Profile, security and signed-in devices share one page. This example uses demonstration data only." />

## Change your name and language

1. Edit **Full name**.
2. Select your interface language under **Language**.
3. Click **Save changes**.
4. Check the confirmation and updated interface.

Use **Upload profile picture** to add a profile image. The language of this documentation is separate: use the language picker at the top of the documentation.

## Change your email address

Choose **Change email**, enter the new address and follow the requested confirmation. Your current password is required. Check the address carefully because you use it to access your account.

## Review devices

**Devices** shows available session information such as device, IP address, location and sign-in time. The current session is marked. Available metadata can differ between logins.

**Sign out all devices** ends all logins, including your current session, after confirmation. Use it for an unfamiliar session and sign in again afterwards. Also review [Secure your account](./security.mdx).
