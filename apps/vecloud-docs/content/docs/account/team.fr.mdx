Si vous travaillez avec des collègues ou un administrateur externe, attribuez à chacun son propre compte et un accès adapté aux sites qu’il gère.

## Qui peut gérer l’équipe ?

Ouvrez **Users** pour consulter les membres. Vos droits déterminent si vous pouvez inviter ou gérer d’autres personnes. Le propriétaire est identifié par **Owner**.

| Rôle | Usage |
| --- | --- |
| Owner | Propriétaire de l’organisation, non supprimable comme un membre ordinaire. |
| Superadmin | Accès étendu à l’organisation. |
| Collaborator | Accès aux sites sélectionnés. |

Ces rôles s’appliquent dans votre propre compte client. **Owner** ou **Superadmin** ne donnent pas accès à la gestion interne de l’infrastructure veCloud. Sélectionnez uniquement le rôle et les sites nécessaires au membre.

## Inviter un membre

Une fois les accès nécessaires définis, préparez l’invitation avec le rôle adapté.

1. Cliquez sur **Invite user**.
2. Renseignez **Name** et **Email**.
3. Choisissez **Invite by email** et/ou **Invite with a link**.
4. Sélectionnez le rôle. Pour certains sites uniquement, choisissez **Collaborator** et cochez les sites concernés.
5. Vérifiez puis cliquez sur **Invite**.

<PortalScreenshot name="team-invite" alt="Formulaire avec Collaborator et uniquement example.test sélectionné" caption="Un Collaborator accède aux sites sélectionnés. Les adresses sont fictives ; cet exemple n’envoie aucune invitation." />

Le lien d’invitation est affiché une seule fois après sa création. Partagez-le uniquement avec le destinataire prévu.

## Modifier ou retirer l’accès

Ouvrez le menu d’un membre actif puis **Manage** pour modifier ses données et droits. Vérifiez les sites sélectionnés avant d’enregistrer.

Pour une invitation en attente, le menu permet un nouvel e-mail, un nouveau lien ou sa révocation. Supprimez un membre actif lorsqu’il n’a plus besoin d’accès. Vérifiez son nom et les conséquences dans la confirmation.

Pour la sécurité personnelle, voir [Sécuriser votre compte](./security.mdx). Les utilisateurs WordPress se gèrent séparément dans le toolkit WordPress.
