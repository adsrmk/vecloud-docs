## Passwort ändern

Öffne **Profile → Security** und wähle **Change** beim Passwort. Gib aktuelles und neues Passwort ein und bestätige. Nutze ein einzigartiges Passwort in einem Passwortmanager.

Kannst du dich nicht anmelden, nutze **Forgot password?** auf der Anmeldeseite und folge den Anweisungen an deine Kontoadresse. Teile weder Passwort noch Wiederherstellungsnachricht.

## Zwei-Faktor-Authentifizierung aktivieren

<Steps>
<Step>
### Einstellung öffnen

Wähle unter **Profile → Security** bei two-factor authentication **Enable**.
</Step>
<Step>
### Authenticator verbinden

Scanne den QR-Code mit deiner Authenticator-App oder verwende den angezeigten manuellen Schlüssel. Teile keinen Screenshot mit diesem Schlüssel.
</Step>
<Step>
### Mit Code bestätigen

Gib den aktuellen sechsstelligen Code ein und bestätige. Prüfe, ob das Panel die Aktivierung meldet. Künftige Anmeldungen benötigen Passwort und App-Code.
</Step>
</Steps>

## Ein Code wird abgelehnt

Nutze einen neuen Code und prüfe die automatische Uhrzeit am Telefon. Wähle das richtige Konto in der App. Verlierst du den Zugriff, wende dich an den Support; teile keine Zugangsdaten, um die Prüfung zu umgehen.

## Eine unbekannte Sitzung

Prüfe **Devices** unten im Profil. Nutze **Sign out all devices** und ändere dein Passwort bei Verdacht auf eine unerwünschte Anmeldung. Prüfe auch die [Teammitglieder](./team.mdx) mit Website-Zugriff.
