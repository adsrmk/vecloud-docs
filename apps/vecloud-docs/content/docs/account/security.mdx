Een goed beveiligd account begint bij je eigen aanmelding. Hieronder stel je je wachtwoord en tweestapsverificatie in en lees je hoe je toegang controleert.

## Wachtwoord wijzigen

Open **Profile** en ga naar **Security**. Kies **Change** bij je wachtwoord. Vul je huidige en nieuwe wachtwoord in en bevestig de wijziging. Gebruik een uniek wachtwoord dat je in een wachtwoordmanager bewaart.

Kun je niet aanmelden? Gebruik **Forgot password?** op het inlogscherm en volg de instructies via je accountadres. Deel geen wachtwoord of herstelbericht met anderen.

## Tweestapsverificatie inschakelen

De koppeling bestaat uit twee delen: je authenticator toevoegen en daarna bevestigen dat de codes werken.

<Steps>
<Step>
### Open de instelling

Kies in **Profile → Security** voor **Enable** bij two-factor authentication.
</Step>
<Step>
### Koppel je authenticator

Scan de QR-code met je authenticator-app of gebruik de getoonde handmatige sleutel. Bewaar deze sleutel niet in een screenshot dat je deelt.
</Step>
<Step>
### Bevestig met een code

Vul de actuele zescijferige code in en bevestig. Controleer dat het panel meldt dat tweestapsverificatie actief is. Bij een volgende aanmelding gebruik je naast je wachtwoord de code uit de app.
</Step>
</Steps>

## Een code wordt geweigerd

Gebruik een verse code en controleer of de klok van je telefoon automatisch wordt ingesteld. Zorg dat je de juiste accountvermelding in je authenticator gebruikt. Ben je je authenticator kwijt, neem dan contact op met support voor hulp met je account; omzeil de verificatie niet door inloggegevens te delen.

## Een onbekende sessie

Bekijk **Devices** onderaan je profiel. Gebruik **Sign out all devices** en wijzig je wachtwoord als je een ongewenste aanmelding vermoedt. Controleer ook de [teamleden](./team.mdx) die toegang hebben tot je websites.
