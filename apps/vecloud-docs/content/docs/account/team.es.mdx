Si colaboras con compañeros o con un administrador externo, asigna a cada persona su propia cuenta y acceso a los sitios que necesita gestionar.

## Quién puede gestionar el equipo

Abre **Users** para ver los miembros. Tus permisos determinan si puedes invitar o gestionar a otros. El propietario aparece como **Owner**.

| Rol | Uso |
| --- | --- |
| Owner | Propietario de la organización; no se elimina como un miembro normal. |
| Superadmin | Acceso amplio a la organización. |
| Collaborator | Acceso a sitios seleccionados. |

Estos roles se aplican dentro de tu cuenta de cliente. **Owner** o **Superadmin** no dan acceso a la gestión interna de infraestructura de veCloud. Selecciona solo el rol y los sitios que necesite cada miembro.

## Invitar a un miembro

Cuando tengas claro el acceso necesario, prepara la invitación con el rol correspondiente.

1. Pulsa **Invite user**.
2. Rellena **Name** y **Email**.
3. Selecciona **Invite by email** y/o **Invite with a link**.
4. Elige el rol. Para sitios concretos, selecciona **Collaborator** y marca esos sitios.
5. Revisa la selección y pulsa **Invite**.

<PortalScreenshot name="team-invite" alt="Formulario con Collaborator y solo example.test seleccionado" caption="Un Collaborator accede a los sitios seleccionados. Las direcciones son ficticias; este ejemplo no envía una invitación." />

El enlace se muestra una sola vez al crearlo. Compártelo únicamente con el destinatario previsto.

## Cambiar o retirar acceso

Abre el menú de un miembro activo y pulsa **Manage** para editar sus datos y permisos. Revisa los sitios antes de guardar.

Una invitación pendiente permite reenviar el correo, generar otro enlace o revocarla. Elimina al miembro activo cuando ya no necesite acceso. Comprueba el nombre y las consecuencias en la confirmación.
