La sécurité de votre compte commence par votre connexion. Les réglages ci-dessous permettent de gérer votre mot de passe, l’authentification à deux facteurs et les accès.

## Changer le mot de passe

Ouvrez **Profile → Security** et cliquez sur **Change** à côté du mot de passe. Saisissez le mot de passe actuel et le nouveau, puis confirmez. Utilisez un mot de passe unique conservé dans un gestionnaire.

Si vous ne pouvez plus vous connecter, choisissez **Forgot password?** sur la page de connexion et suivez les instructions envoyées à votre adresse. Ne partagez ni mot de passe ni message de récupération.

## Activer la double authentification

La configuration comporte deux parties : ajouter votre application, puis confirmer que ses codes fonctionnent.

<Steps>
<Step>
### Ouvrir le réglage

Dans **Profile → Security**, cliquez sur **Enable** à côté de two-factor authentication.
</Step>
<Step>
### Associer l’application

Scannez le QR code avec votre application d’authentification ou utilisez la clé manuelle affichée. Ne partagez pas de capture contenant cette clé.
</Step>
<Step>
### Confirmer avec un code

Saisissez le code actuel à six chiffres et confirmez. Vérifiez que le panneau indique l’activation. Les prochaines connexions demanderont votre mot de passe et le code de l’application.
</Step>
</Steps>

## Un code est refusé

Utilisez un nouveau code et vérifiez le réglage automatique de l’heure du téléphone. Sélectionnez le bon compte dans l’application. Si vous perdez l’accès à celle-ci, contactez le support ; ne partagez pas vos identifiants pour contourner la vérification.

## Une session inconnue

Consultez **Devices** en bas de votre profil. Utilisez **Sign out all devices** et changez votre mot de passe en cas de connexion indésirable. Vérifiez aussi les [membres de l’équipe](./team.mdx) ayant accès à vos sites.
