Votre profil regroupe vos réglages personnels. Vous pouvez y tenir vos coordonnées à jour et choisir la langue dans laquelle vous souhaitez travailler.

## Ouvrir votre profil

Choisissez **Profile** dans la navigation principale. **My account** rassemble profil, sécurité et appareils. Ces réglages concernent votre propre connexion.

<PortalScreenshot name="profile" alt="Champs du profil, langue et adresse de connexion du compte de démonstration" caption="Modifiez votre nom et votre langue dans Profile. Votre adresse de connexion figure dans le même encadré." />

## Modifier nom et langue

1. Modifiez **Full name**.
2. Choisissez votre langue dans **Language**.
3. Cliquez sur **Save changes**.
4. Vérifiez la confirmation et l’interface mise à jour.

**Upload profile picture** ajoute une photo. La langue de cette documentation se règle séparément avec son sélecteur en haut de page.

## Modifier l’adresse e-mail

Choisissez **Change email** dans **Profile**. Remplacez l’adresse, saisissez votre mot de passe actuel et sélectionnez **Save changes**. Après confirmation, vérifiez l’adresse affichée sous **Email address**. C’est celle que vous utilisez pour vous connecter.

<PortalScreenshot name="profile-email" alt="Profil avec le champ Current password pour changer l’adresse e-mail" caption="Saisissez la nouvelle adresse et le mot de passe actuel avant de choisir Save changes. Le champ du mot de passe est vide dans l’exemple." />

## Consulter les appareils

**Devices** affiche les données de session disponibles : appareil, IP, localisation et date de connexion. La session actuelle est signalée. Les métadonnées peuvent varier selon la connexion.

**Sign out all devices** ferme toutes les sessions, y compris la vôtre, après confirmation. Utilisez cette action en cas de session inconnue, puis reconnectez-vous. Consultez aussi [Sécuriser votre compte](./security.mdx).
