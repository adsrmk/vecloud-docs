## Temporarily disable a website

Open the website’s action menu and choose **Disable website**. Check the domain in the confirmation. This disables the website without choosing to delete its content.

Use **Enable website** to enable a website you disabled yourself when this action is available. A provider suspension may require additional assistance; changing a status alone does not resolve its cause.

## Delete a website

<Callout type="warning" title="Keep the data you need">
Deletion is a significant action. Save required files, database exports and email data separately. Do not assume that recovery remains available after deletion.
</Callout>

1. Check the website and linked domains being removed.
2. Open its action menu and choose **Delete website**.
3. Read the warning and check the domain again.
4. Confirm only when you no longer need the website and its content.
5. Check the current domain list afterwards.

Deleting a website does not automatically cancel its domain registration with a registrar. Separately review DNS and external integrations still pointing to the deleted website.

## No clear confirmation

Refresh the domain list or reopen the website first. The server may have completed the action despite a delayed response. Do not repeat deletion based only on an error toast. Record the domain, time and message if support needs to check the status.

Save any content you need before deleting the source. Existing staging websites may also offer the actions under [Manage and publish staging](./copy.mdx), depending on your permissions.
