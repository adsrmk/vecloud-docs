A website may need to move to another customer organization when responsibility changes. Before starting, confirm which organization should manage it after the transfer.

## Check the destination

**Transfer ownership** is an administration action for authorised roles. It is not a registrar domain transfer or an invitation for another team member. To grant someone access only, use [users and roles](../account/team.mdx).

## Perform the transfer

1. Open **Domains → your website → Overview**.
2. Open **Website actions** and choose **Transfer ownership**.
3. Select the intended **New customer organization**.
4. Check the domain and destination, then select **Continue**.
5. Check the website in its new organisation and review who has access.

The destination must be an active customer organisation beneath the current organisation. Choosing the same organisation again or supplying an arbitrary external account is not supported. If no destination is available, have the organisation relationship and permissions checked.

Ownership transfer changes who manages the website. Review access arrangements, services and backup responsibilities beforehand. Sharing existing passwords is not a substitute for transferring ownership correctly.

If the result is unconfirmed, first check which organisation now owns the website before retrying. This screen is not checkout and does not transfer domain registration.
