Empieza por el nombre con el que se accederá al sitio. El tipo de dominio determina si necesitas un espacio independiente o utilizar un sitio existente.

## Antes de empezar

Utiliza un dominio que controles y comprueba que tu plan permita otro sitio. Añadirlo al panel no registra el nombre en un registrador. Después debes dirigir el DNS al alojamiento correcto.

## Elegir el tipo

<Tabs items={['Addon', 'Subdomain', 'Alias']}>
<Tab value="Addon" keepMounted>
Usa **Addon** para un sitio independiente. Introduce el dominio completo sin protocolo, ruta o prefijo `www.` no deseado. Se crea el espacio web; instala una aplicación después desde **Apps**.

<PortalScreenshot name="add-domain" alt="Formulario con Addon y el dominio ficticio demo-site.test" caption="El formulario comienza con Domain type y Domain. La aplicación se elige después, desde el sitio." />
</Tab>
<Tab value="Subdomain" keepMounted>
Usa **Subdomain** para un nombre bajo un dominio existente. Elige el dominio principal e introduce solo la parte nueva, como `shop`. Revisa el nombre combinado antes de crearlo.

<PortalScreenshot name="add-subdomain" alt="Subdomain con shop y el dominio existente example.test" caption="Introduce shop. El dominio existente junto al campo completa shop.example.test." />
</Tab>
<Tab value="Alias" keepMounted>
Usa **Alias** para asociar otro dominio a un sitio existente. Elige ese destino e introduce el alias. Es otro nombre para el mismo sitio, no una redirección HTTP a otra dirección.

<PortalScreenshot name="add-alias" alt="Formulario Alias con example.test como destino" caption="Revisa el sitio existente y el dominio adicional. En el ejemplo, alias.example.test se añade a example.test." />
</Tab>
</Tabs>

## Crear el dominio

Una vez elegido el tipo de dominio, completa el formulario con los datos correspondientes.

1. Entra en **Domains → Add domain**.
2. Elige el tipo y rellena sus datos.
3. Revisa nombre y sitio de destino, si corresponde.
4. Pulsa **Create** y espera la confirmación.

## Después de crearlo

Abre el sitio y comprueba **DNS settings** y **SSL certificates**. El DNS público debe apuntar al alojamiento correcto antes de probar el acceso o solicitar un certificado. Instala WordPress u otra aplicación compatible desde **Apps → Add application**.

## Formulario bloqueado

Un plan lleno o inactivo puede impedir la creación. Un alias necesita un sitio existente adecuado. Si **Create** devuelve un error incierto, comprueba la lista antes de volver a añadir el mismo dominio.
