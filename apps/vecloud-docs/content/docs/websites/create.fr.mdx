Commencez par le nom que les visiteurs utiliseront pour accéder au site. Le type de domaine détermine si vous créez un espace distinct ou utilisez un site existant.

## Avant de commencer

Utilisez un domaine que vous contrôlez et vérifiez la capacité de votre offre. L’ajout au panneau n’enregistre pas le domaine chez un registrar. Il faut ensuite diriger le DNS vers le bon hébergement.

## Choisir le type

<Tabs items={['Addon', 'Subdomain', 'Alias']}>
<Tab value="Addon">
Utilisez **Addon** pour un site distinct. Saisissez le domaine complet sans protocole, chemin ou préfixe `www.` non souhaité. L’espace web est créé ; installez ensuite une application dans **Apps**.
</Tab>
<Tab value="Subdomain">
Utilisez **Subdomain** pour un nom sous un domaine existant. Choisissez le parent et saisissez uniquement la nouvelle partie, par exemple `shop`. Vérifiez le domaine composé avant création.
</Tab>
<Tab value="Alias">
Utilisez **Alias** pour associer un autre domaine à un site existant. Choisissez la destination et saisissez l’alias. C’est un nom supplémentaire du même site, pas une redirection HTTP vers une autre adresse.
</Tab>
</Tabs>

## Créer le domaine

Une fois le type de domaine choisi, remplissez le formulaire avec les informations correspondantes.

1. Ouvrez **Domains → Add domain**.
2. Choisissez le type et renseignez ses données.
3. Vérifiez le nom et la destination éventuelle.
4. Cliquez sur **Create** et attendez la confirmation.

<PortalScreenshot name="add-domain" alt="Formulaire Addon avec le domaine fictif demo-site.test" caption="Le formulaire commence par Domain type et Domain. L’application se choisit ensuite dans le site." />

## Après la création

Ouvrez le site et vérifiez **DNS settings** et **SSL certificates**. Le DNS public doit pointer vers le bon hébergement avant de tester l’accès ou demander un certificat. Installez WordPress ou une autre application prise en charge dans **Apps → Add application**.

## Formulaire bloqué

Une offre pleine ou inactive peut empêcher la création. Un alias nécessite un site existant adapté. Après une erreur incertaine de **Create**, consultez la liste avant d’ajouter de nouveau le même domaine.
