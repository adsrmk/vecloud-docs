Le nom de domaine est généralement votre point de départ pour gérer un site dans le panel. Son ouverture rassemble les réglages de l’hébergement correspondant.

## Site ou domaine ?

**Domains** affiche les sites que vous pouvez gérer. Chaque site possède ses fichiers, applications et réglages. Un alias supplémentaire peut pointer vers le même site sans créer une autre installation.

## Vue d’ensemble du site

Cliquez sur un domaine puis **Overview**. Vous y trouvez les données disponibles d’état, d’utilisation et de connexion ainsi que les applications installées. Elles dépendent des services et droits du site.

Utilisez les informations de connexion de ce site. Ne copiez pas une adresse ou un utilisateur d’un autre site. Domaine public et adresse interne de connexion peuvent avoir des usages différents.

## Gérer les rubriques

La barre fixe ouvre notamment **Apps**, **Files**, **Databases**, **DNS settings**, **Backups** et **SSL certificates**. Les réglages concernent le site ou domaine sélectionné. Certains services, dont le courrier ou des toolkits particuliers, doivent être activés pour ce site.

Commencez par [Ajouter un domaine](./create.mdx). Si vous avez un staging, voir [Gérer et publier le staging](./copy.mdx).

## Avant une modification importante

Créez une [sauvegarde](../backups/index.mdx), vérifiez la destination et conservez ce qui permet d’annuler le changement. [Désactiver et supprimer](./lifecycle.mdx) ont des conséquences différentes sur le contenu.
