¿Tu sitio necesita más capacidad o una función de otro plan? Abre **Domains → tu sitio → Overview**. **Plan usage** muestra el plan actual y cuánto estás usando.

<PortalScreenshot name="website-overview" alt="Uso del plan y ancho de banda en Overview" caption="Plan usage muestra tu plan y la capacidad disponible." />

## Solicitar el cambio

Indica a [soporte](../help/index.mdx) el dominio, el plan deseado y la función o capacidad que necesitas. Especifica si el sitio es de producción o de staging. Así veCloud puede comprobar qué plan encaja y si tiene capacidad para el sitio.

## Comprobar el sitio

Pregunta si el cambio afecta a los servicios, a las versiones de PHP o a tareas programadas. Tras la confirmación, revisa **Plan usage** y prueba las funciones que motivaron el cambio.
