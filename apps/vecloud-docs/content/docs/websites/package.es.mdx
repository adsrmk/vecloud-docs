Si cambian las necesidades de hosting, otro plan disponible puede encajar mejor. Revisa qué funciones y límites necesitará el sitio después del cambio.

## Qué cambia

**Change plan** asigna un sitio existente a una suscripción de hosting disponible. Es una acción administrativa, no una página de pago ni compra. Necesitas permisos adecuados y un plan de destino válido.

## Cambiar el plan

1. Abre **Domains → tu sitio → Overview**.
2. Entra en **Website actions → Change plan**.
3. Elige **New plan**, comprobando nombre y número de suscripción.
4. Pulsa **Continue** y comprueba el plan resultante.
5. Revisa funciones, cuotas y versiones PHP disponibles.

El destino debe tener capacidad y permiso para el tipo de sitio, incluido staging cuando corresponda. Los planes mostrados pueden fallar comprobaciones de elegibilidad. Repetir la misma solicitud no resuelve una cuota agotada.

La asignación no copia el sitio, mueve el servidor ni modifica delegación DNS. Cambia otros ajustes solo si es necesario después. Consulta al administrador o soporte si falta el plan deseado.

Si el resultado es incierto, actualiza primero los datos. Los [gráficos de recursos](../performance/resources.mdx) muestran consumo, pero no contratan ni cambian planes.
