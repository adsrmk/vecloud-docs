Wenn sich die Hostinganforderungen ändern, kann ein anderer verfügbarer Tarif besser passen. Prüfe vorab, welche Funktionen und Limits die Website danach benötigt.

## Was ändert sich?

**Change plan** ordnet eine bestehende Website einem verfügbaren Hostingabonnement zu. Das ist eine Verwaltungsaktion, keine Zahlung oder Neubestellung. Du brauchst passende Rechte und ein geeignetes Zielpaket.

## Paket ändern

1. Öffne **Domains → deine Website → Overview**.
2. Wähle **Website actions → Change plan**.
3. Wähle **New plan** und prüfe Name sowie Abonnementnummer.
4. Wähle **Continue** und kontrolliere das zugeordnete Paket.
5. Prüfe verfügbare Funktionen, Kontingente und PHP-Versionen.

Das Ziel benötigt freie Kapazität und die Erlaubnis für den Websitetyp, gegebenenfalls einschließlich Staging. Angezeigte Pakete können bei der Prüfung ungeeignet sein. Wiederholte Anfragen lösen keinen Kontingentfehler.

Die Zuordnung kopiert keine Website, verschiebt keinen Server und ändert keine DNS-Delegation. Passe weitere Einstellungen nur bei Bedarf an. Fehlt das Zielpaket, wende dich an Verwaltung oder Support.

Bei ungewissem Ergebnis lade zuerst die Websitedaten neu. [Ressourcendiagramme](../performance/resources.mdx) zeigen Nutzung, bestellen oder ändern aber kein Paket.
