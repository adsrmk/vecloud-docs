El nombre de dominio suele ser el punto de partida para gestionar un sitio en el panel. Al abrirlo, encontrarás los ajustes de su entorno de hosting.

## Sitio o dominio

**Domains** muestra los sitios que puedes gestionar. Cada sitio tiene archivos, aplicaciones y ajustes propios. Un alias adicional puede apuntar al mismo sitio sin crear otra instalación.

<PortalScreenshot name="domains" alt="Lista con el sitio de demostración disponible" caption="Busca el dominio y abre el sitio. Comprueba el dominio de la barra superior antes de modificar ajustes." />

## Resumen del sitio

Haz clic en un dominio y abre **Overview**. Verás los datos disponibles de estado, uso y conexión y las aplicaciones instaladas. Dependen de los servicios y permisos del sitio.

Utiliza sus propios datos de conexión del panel. No copies una dirección o usuario de otro sitio. El dominio público y una dirección interna de conexión pueden tener finalidades distintas.

## Gestionar secciones

La barra lateral fija abre **Apps**, **Files**, **Databases**, **DNS settings**, **Backups** y **SSL certificates**, entre otras secciones. Los ajustes pertenecen al sitio o dominio seleccionado. Algunos servicios, como correo o ciertos toolkits, requieren estar habilitados para ese sitio.

Empieza con [Añadir un dominio](./create.mdx). Si tienes un staging, consulta [Gestionar y publicar staging](./copy.mdx).

## Antes de un cambio importante

Crea una [copia](../backups/index.mdx), comprueba el destino y guarda lo necesario para deshacer el cambio. [Desactivar y eliminar](./lifecycle.mdx) tienen consecuencias distintas para el contenido.
