## Website oder Domain?

**Domains** zeigt die Websites, die du verwalten darfst. Eine Website besitzt eigene Dateien, Anwendungen und Hostingeinstellungen. Ein zusätzlicher Alias kann auf dieselbe Website zeigen, ohne eine zweite Installation anzulegen.

## Website-Übersicht

Klicke auf eine Domain und öffne **Overview**. Dort findest du verfügbare Status-, Verbrauchs- und Verbindungsdaten sowie installierte Anwendungen. Die Angaben hängen von Diensten und Rechten ab.

Nutze die Verbindungsdaten dieser Website im Panel. Übernimm keine Adresse oder Benutzernamen einer anderen Website. Öffentliche Domain und interne Verbindungsadresse können verschiedenen Zwecken dienen.

## Bereiche verwalten

Die feste Seitenleiste öffnet unter anderem **Apps**, **Files**, **Databases**, **DNS settings**, **Backups** und **SSL certificates**. Einstellungen gehören zur ausgewählten Website oder Domain. Manche Dienste, etwa E-Mail oder bestimmte Toolkits, müssen für die Website aktiviert sein.

Beginne mit [Eine Domain hinzufügen](./create.mdx). Wenn du eine Staging-Website hast, siehe [Staging verwalten und veröffentlichen](./copy.mdx).

## Vor einer größeren Änderung

Erstelle ein [Backup](../backups/index.mdx), prüfe das Ziel und sichere Angaben für eine Rücknahme. [Deaktivieren und Löschen](./lifecycle.mdx) haben unterschiedliche Folgen für Website-Inhalte.
