## What changes?

**Change plan** assigns an existing website to an available hosting subscription. It is an administration action, not a payment page or purchase of a new subscription. You need suitable administration rights and an eligible destination plan.

## Change the plan

1. Open **Domains → your website → Overview**.
2. Open **Website actions → Change plan**.
3. Choose **New plan**, checking its name and subscription number.
4. Select **Continue** and check the website’s resulting plan.
5. Review available features, quotas and PHP versions.

The destination needs capacity and permission for the website type, including staging where applicable. Listed plans may still fail eligibility checks. Repeating the same request does not resolve a quota error.

Reassignment does not copy the website, move its server or change domain delegation. Change other settings only if needed afterwards. Contact the administrator or support if the intended plan is missing.

If the outcome is uncertain, reload the website data first. [Resource charts](../performance/resources.mdx) show usage but do not order or change a plan.
