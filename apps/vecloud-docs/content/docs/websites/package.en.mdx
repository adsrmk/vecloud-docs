Does your website need more capacity or a feature from another plan? Open **Domains → your website → Overview**. **Plan usage** shows the current plan and how much of it is in use.

<PortalScreenshot name="website-overview" alt="Plan usage and bandwidth in Overview" caption="Plan usage shows your plan and available capacity." />

## Request a change

Tell [support](../help/index.mdx) the domain name, the plan you want and the feature or capacity you need. Include whether this is a production or staging website. veCloud can check which plan fits and whether it has capacity for the site.

## Check your website

Ask whether the change affects services, PHP versions or any scheduled work. Once the change is confirmed, check **Plan usage** again and test the features you requested it for.
