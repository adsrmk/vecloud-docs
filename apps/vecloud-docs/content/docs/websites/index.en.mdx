## Website or domain?

**Domains** lists the websites you can manage. A website has its own files, applications and hosting settings. An additional alias can point to the same website without creating a second installation.

<PortalScreenshot name="domains" alt="List of the available demonstration website" caption="Find the domain and open the website. Check the domain in the topbar before changing settings." />

## Website overview

Click a domain and open **Overview**. It shows available status, usage and connection information alongside installed applications. The information depends on the services and permissions for this website.

Use connection details from the selected website in the panel. Do not copy an address or username from another website. The public domain and an internal connection address can serve different purposes.

## Manage sections

The fixed sidebar opens sections including **Apps**, **Files**, **Databases**, **DNS settings**, **Backups** and **SSL certificates**. Settings belong to the selected website or domain. Some services, such as email or particular toolkits, are only available when enabled for this website.

Start a new website with [Add a domain](./create.mdx). If you have a staging website, see [Manage and publish staging](./copy.mdx).

## Before a major change

Create a [backup](../backups/index.mdx), check the target and record what you need to undo the change. [Disabling and deleting](./lifecycle.mdx) have different consequences for your website content.
