## 1. Connectez-vous à Control Panel

Ouvrez [panel.vecloud.eu](https://panel.vecloud.eu) et connectez-vous avec votre compte veCloud. Allez dans **Domains** pour voir vos sites.

## 2. Ajoutez votre domaine

Choisissez **Add domain**, sélectionnez le type et saisissez le nom de domaine. Utilisez **Addon** pour un site indépendant, **Subdomain** pour un sous-domaine ou **Alias** pour associer un domaine supplémentaire à un site existant.

Consultez les possibilités dans [Sites web et domaines](./websites/index.mdx).

## 3. Vérifiez le DNS

Ouvrez votre site et allez dans **DNS settings**. Vérifiez que le domaine pointe vers le bon hébergement. Si vous gérez le DNS ailleurs, modifiez les enregistrements chez cet autre fournisseur.

Les modifications DNS ne deviennent pas visibles partout en même temps. Continuez une fois que votre domaine atteint le bon site.

## 4. Installez votre site

Pour WordPress, allez dans **Apps** et choisissez **Add application**. Terminez l’installation, puis ouvrez **Toolkit** pour gérer WordPress.

Pour un site personnalisé, déposez vos fichiers via **Files** ou votre connexion FTP/SFTP disponible. Consultez [Fichiers et bases de données](./bestanden-databases.mdx).

## 5. Activez HTTPS

Allez dans **SSL certificates**. Si nécessaire, demandez un certificat avec **Request certificate**. Vérifiez son état, puis activez **Enforce HTTPS** pour que les visiteurs se connectent toujours en HTTPS.

## 6. Consultez vos sauvegardes

Ouvrez **Backups** et vérifiez les points de restauration disponibles. Lisez [Sauvegardes et restauration](./backups/index.mdx) avant de restaurer du contenu.
