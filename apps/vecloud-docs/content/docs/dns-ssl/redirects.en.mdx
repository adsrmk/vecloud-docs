## Add a redirect

Open your website and choose **Redirects → Add redirect**. Rules belong to the selected website; select only the intended domains within the form.

1. Choose **301** for a permanent move or **302** for a temporary redirect.
2. Review the domains. A single-domain website has a fixed selection; with multiple domains you can select the intended ones.
3. Enter the path. The form already supplies `/`; entering `old` describes `/old`. Leave it empty for the root path `/`.
4. Choose the destination protocol and enter the rest of the destination address. Do not repeat `https://` if it is already selected separately.
5. Save and test the original URL in a new private window.

An alias lets an extra domain use the same website. A redirect forwards the browser and changes its address. Use [an alias](../websites/create.mdx) when you do not want forwarding.

## Edit and delete

Use **Edit** on the intended rule, change its values and save. **Delete** requires confirmation. Test the original URL afterwards. Browsers may remember an earlier permanent 301 even after a rule changes; a clean test avoids misleading results.

## Redirect-loop warnings

The panel may warn about a possible loop or a chain that cannot be fully checked. Read the displayed addresses. Fix a destination that leads back to its source, directly or through other rules. Use the save-anyway action only if you understand the consequences.

Also check WordPress, enforced HTTPS and external proxies when investigating a loop. The absence of a warning does not guarantee that every external or application rule has been checked.

## Advanced rewrite rules

If internal or other non-standard rules exist, the page shows an expandable advanced rewrites section. It lets you edit patterns, substitutions, flags and conditions. These rules may be required for application routing; do not remove them merely to clean up a visible redirect.

If a message says the configuration has changed or is still being processed, refresh the current rules first. Do not overwrite a newer configuration with an old draft.
