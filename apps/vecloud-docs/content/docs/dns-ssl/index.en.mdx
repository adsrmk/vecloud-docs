DNS connects your domain name to services such as your website and email. Start by identifying where DNS is managed, then update the records you need.

## Check who hosts your DNS

Open **Domains → your website → DNS settings**. The page shows zones for domains attached to this website. Saved changes become public only when the active nameservers serve this zone, or when it is synchronized through the [Cloudflare integration](./cloudflare.mdx).

With external nameservers and no synchronization, edit records at that external provider. Adding an NS record in this table does not change the nameserver delegation at your registrar.

## Add a record

Once you have confirmed the correct zone, add the required record as follows.

<Steps>
<Step>
### Open the form
Choose **Add record** in the correct domain’s DNS table.
</Step>
<Step>
### Enter the type, hostname and value
Use `@` for the root domain or a name such as `www` for a subdomain. Copy the value supplied by the service you want to connect. MX records have priority and mail server fields; SRV records have priority, weight, port and target fields.
</Step>
<Step>
### Choose the TTL and save
Use the default TTL, or turn that option off and enter seconds. Choose **Add record** and check the new row.
</Step>
</Steps>

## Choose a record type

| Type | Purpose |
| --- | --- |
| A / AAAA | Hostname to an IPv4 or IPv6 address |
| CNAME | Hostname to another hostname, without a protocol or URL path |
| MX | Receiving mail server and priority |
| TXT | Domain verification, SPF, DKIM or DMARC |
| SRV | Host and port for a particular service |
| CAA | Permitted certificate authorities |
| NS / DS / PTR | Delegation, DNSSEC or reverse DNS information where applicable |

SPF is also available as a type. Use a TXT record for a new SPF policy. A PTR record in an ordinary domain zone does not change reverse DNS for a hosting IP; its IP operator controls that.

## Edit, delete and verify

Use **Edit** on the intended row and save the new values. Deletion requires confirmation. Keep a copy of the old value before replacing a working record. DNS caches may continue returning old answers until the previous TTL expires; saving repeatedly does not speed that up.

## SOA settings

The zone also shows its responsible nameserver, administrative address and **Expires**, **Refresh**, **Retry** and **TTL** values. The edit action opens the SOA form; times are in seconds. Change these advanced values only when required by your DNS setup. Editing SOA does not move your domain to different nameservers.

For email, use [routing and authentication](./mail-routing.mdx). To forward a web address, use [Redirects](./redirects.mdx), not a DNS record.
