Wenn unerwünschter Traffic wiederholt von derselben Adresse oder demselben Netzwerk kommt, kannst du den Zugriff gezielt einschränken. Hier verwaltest du die entsprechenden Sperren.

## Für welchen Bereich gilt die Sperre?

Öffne deine Website und **IP deny** in der Seitenleiste direkt unter **SSL certificates**. Die Funktion verwaltet Nginx-Sperren für die zugeordneten Domains dieser Website. Sie ist keine serverweite Firewall und sperrt keine Mail- oder SSH-Anmeldungen.

## Adressen hinzufügen

1. Wähle **Add IP addresses** neben dem Seitentitel.
2. Gib je Zeile eine IPv4-, IPv6-Adresse oder ein CIDR-Netz ein.
3. Prüfe besonders den Umfang der CIDR-Regeln. Ein ganzes Netz kann auch erwünschte Besucher ausschließen.
4. Wähle **Add IP addresses** und prüfe die Tabelle.

Diese Werte sind ausschließlich Dokumentationsbeispiele:

```text
192.0.2.40
198.51.100.0/24
2001:db8::/32
```

Die Liste unterstützt bis zu **250 Adressen oder Netzregeln**. CIDR-Netze können nach dem Speichern normalisiert erscheinen. Gib keine Domains, URLs oder Hostnamen ein.

## Sperre entfernen

Wähle **Delete** neben der Adresse und bestätige. Prüfe, ob die Zeile verschwindet, und teste den Zugriff aus diesem Netz. Das Entfernen hebt keine unabhängige Sperre in einer externen Firewall oder einem Proxy auf.

Bei unterschiedlichen Listen der Domains zeigt das Panel einen Hinweis und eine Aktion zum Anwenden der gemeinsamen Liste auf alle Domains. Prüfe zuerst, ob wirklich jede angezeigte Adresse überall gesperrt werden soll.

## Verarbeitung oder unbestätigtes Ergebnis

Bei einer laufenden Änderung oder einem unbestätigten Ergebnis aktualisierst du zuerst die Daten. Prüfe vor erneutem Speichern, ob die gewünschte Adresse bereits vorhanden oder entfernt ist. Dauert die Verarbeitung weiter an, bitte den Support um eine Statusprüfung.

Nutze **IP deny** zum Hinzufügen und Entfernen von Adressen. veCloud verwaltet die zugrunde liegende Webserverkonfiguration; dafür benötigst du keinen VirtualHost-Editor.

## Andere Webserver und Proxys

**IP deny** ist für Nginx verfügbar. Apache kann separate Erlaubnis-/Sperrregeln unter **SSL certificates → IP access** anzeigen. Nur ausgewählte Adressen zuzulassen schließt alle übrigen Besucher aus und unterscheidet sich von einer normalen Sperrliste.

Bei einem externen Proxy muss der Server die tatsächliche Besucher-IP erkennen. Sperre keine gemeinsam genutzte Proxyadresse, um einen Besucher auszuschließen. Bitte um Hilfe, wenn unklar ist, welche Adresse der Server sieht.
