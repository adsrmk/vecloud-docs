## Gérez les fichiers

Ouvrez votre site et allez dans **Files**. Parcourez les dossiers avec la liste de fichiers et le chemin affiché en haut. Sélectionnez un fichier pour voir les actions disponibles.

L’éditeur permet de modifier les fichiers texte compatibles directement dans le panel. Enregistrez avec **Save**. Pour transférer de grandes quantités de fichiers, utilisez l’accès FTP/SFTP disponible.

## Ouvrez une base de données

Allez dans **Databases** au sein de votre site. Choisissez la base à consulter ou à gérer. Vérifiez toujours son nom, son type et l’utilisateur associé avant toute modification.

Pour les bases MySQL/MariaDB compatibles, utilisez l’action phpMyAdmin pour ouvrir leur administration depuis le panel.

## Utilisateurs de bases de données

Utilisez les utilisateurs et leurs droits pour contrôler l’accès. Copiez les paramètres de connexion du panel dans votre application et traitez le mot de passe comme un identifiant de connexion.

## Importez et restaurez

L’importation SQL et la restauration d’une sauvegarde sont deux actions différentes. Pour une importation, utilisez l’option d’importation de la base choisie. Pour récupérer une sauvegarde existante, suivez [Sauvegardes et restauration](./backups.mdx).
